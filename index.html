Informe Técnico del Sistema CRUD - Gestión del Restaurant

1. Introducción y Propósito

Este documento detalla el desarrollo del sistema informático CRUD para la administración del menú, control de stock (platos principales, entradas, bebidas de "El Pipa" y postres) y control de usuarios del restaurant.

Registro de Usuarios

Permite dar de alta al personal de salón y administración con validación de datos básica.

Inicio de Sesión (Login)

Pantalla de acceso centralizada que valida las credenciales y redirige según el rol correspondiente.

2. Panel de Administrador y Operaciones

Si el usuario ingresa con rol admin, el sistema habilita el panel de control exclusivo para el menú:

  • Ver Tabla: Visualización en tiempo real de la base de datos de platos (milanesas, asado, empanadas del tucu, postres, etc.).
  • Editar: Modificación de precios, descripciones o ingredientes de las comidas y bebidas.
  • Archivar: Ocultar temporalmente platos o bebidas fuera de temporada en lugar de borrarlos definitivamente.

3. Diseño y Códigos de Color

Se mantuvo la misma línea visual institucional de la página web del restaurant:

Rojo Bordó Principal: #800000 (Encabezados y botones)

Fondo Trigo / Crema: #f5deb3 (Fondo general del sitio)

Gris Oscuro / Negro: #333333 (Menú de navegación y textos)

4. Medidas de Seguridad

  • Cifrado de Contraseñas: Las claves del personal se almacenan utilizando hash seguro.
  • Control de Roles (RBAC): Restricción de rutas en el servidor para impedir que cuentas comunes accedan a los botones de edición del administrador.
  • Protección SQL: Uso de consultas preparadas para evitar ataques de inyección de código.
